# Daily Usage Report Generator

To regenerate the daily usage report artifacts, ensure the insights-board server is running at `http://127.0.0.1:8901` and run `python3 report/build_report.py [out_dir]` (defaults to `report/out/`). The script uses system Python 3.14 (stdlib + PIL + numpy) to query platform usage endpoints (`/api/opencode`, `/api/claudecode`, `/api/antigravity`, `/api/hermes` with `/api/summary` fallback) and produces three artifacts: `usage-report.png` (a 1200x675 dark Discord-themed 7-day token bar chart excluding cache), `report.txt` (a compact, skimmable summary under 8 lines with today's deltas, all-time totals, and a one-line cache note), and `embed.json` (a ready-to-POST Discord embed object with dynamic activity coloring, inline fields, and timestamp).
