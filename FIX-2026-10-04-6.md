# Forge Console — Fix Brief 6 (2026-10-04): PROJECTS node legibility

Nathan's standard: "the projects node is really hard to read". One targeted change
in `web/app.js` (drawProjectsNode + the projectsNode sizing). Do not touch anything
else (edges, geometry of other nodes, Insights/Ideas tabs).

Root cause (verified in code — confirm):
- `projW = Math.max(200, Math.min(260, ...))` — width is CAPPED at 260px, so long
  names (e.g. `hydrocarbon-forge-website`, 26 chars) get truncated with "…".
- Row font is `10px JetBrains Mono` (tiny) and inactive rows are `#7a7b84` (dim).
- Pitch is 28px.
Net effect: a 260px-wide box of 14 rows of 10px text = mush.

Fix (make it a LEGIBLE list — the node can be big, that was already approved):
1. Size the node to its content: `projW = Math.max(260, Math.ceil(maxTw) + padding)`
   with a HIGHER cap (e.g. 360) or no hard cap below 360. Longest name must fit
   UNTRUNCATED. Compute with the actual row font (below).
2. Row font: 10px → **12px** JetBrains Mono (active rows 600 weight, accent color;
   inactive rows regular weight but brighten the color to ~`#a8a9b3`).
3. Pitch 28 → **32px** to give the bigger font room; header title 12px → 13px.
4. Keep the connector dots (right edge, active = accent+glow, inactive dim), the
   count sub-line, and the FILESYSTEM/PROJECTS edges exactly as they are now —
   they anchor to `pitch`/ports, so if pitch or height changes, recompute
   `rowDy`/port positions consistently (they derive from `projH`, `pitch`, `headerH` —
   just make sure they stay in sync).
5. Height follows: `projH = headerH + numProjects * pitch + 10`. At 14 rows that's
   ~470px — fine. Verify it still fits at 1280×800 (if the whole scene gets too tall,
   prefer a slightly smaller pitch over re-introducing truncation; do NOT shrink the
   font below 11px).

Verify:
- `node --check web/app.js` clean.
- `systemctl --user restart forge-console`; `/api/health` + `/api/flow` 200.
- In the browser at 1280×800: every project name fully visible (no "…") at 12px;
  the node box is disjoint from FILESYSTEM and the hub; the active-row connector
  dots + hub edges still land on the right edge at the row centers; leave-and-return
  re-renders.
- End with a one-line report: new width, font, pitch, and whether any name still
  truncates.
